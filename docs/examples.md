<h2 align="center">💡 Examples</h2>

GoForge is still under active development — full worked examples will be added once the Use Case layer and more resources land.

For now, here's the current end-to-end flow using what's already available:

```bash
goforge init myapp
cd myapp
goforge add --modules order,client
goforge add http
goforge add mysql
goforge setup
```

See [Commands](commands.md), [Modules](modules.md), and [Resources](resources.md) for what each step does.
